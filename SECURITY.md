# Security Policy

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/prashantbhudwal/slop-shame/security/advisories/new)
(**Security** tab → **Report a vulnerability**). Don't open a public issue.

Include what's affected, steps to reproduce, and the impact you see. You'll
get a reply within a week, and credit in the fix if you want it.

## Scope

Things we especially care about:

- anything that makes the extension send data off your machine;
- script injection into linkedin.com or extension pages via post content;
- other sites being able to read the Hall of Slop data.

## Supported versions

Only the latest release (or `main`, before the first release) gets fixes.
