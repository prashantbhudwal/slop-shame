Support

Slop Shame is currently in development. For questions, bugs, feature requests, or privacy concerns, open a GitHub issue.

Issues are public. Please leave out private feed text, account details, and identifiable screenshots. Include your browser version, extension version, and steps to reproduce a bug.

Reporting a security problem

Use GitHub private vulnerability reporting. Do not post exploit details in a public issue.

How do scores work?

The extension matches bundled writing-pattern rules locally. A Slop Index describes those signals; it cannot establish who wrote a post or which tools they used.

How do I remove local data?

The current development version has no user-facing clear control. Uninstalling removes browser-managed extension data. Copied text and downloaded images must be deleted separately. Read the privacy policy for retention details.

Does it act on my LinkedIn account?

Destroy hides a post in your own view. Cards are copied or downloaded only when you choose. It does not automatically publish, message, or delete the original post.
